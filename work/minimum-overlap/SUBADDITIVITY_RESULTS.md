# Dyadic subadditivity: separate research result

The public Drynshock claim on the user-supplied problem page prompted an
independent derivation of F(s+t)<=F(s)+F(t), F(t)=p(t)+p(-t), directly
from the probability-distance triangle inequality. This is not a novelty
claim. SUBADDITIVITY_RETURN.md supplies the universal argument and exact
dyadic-hat kernel return. No hypothesis that h is a step density is used.

The standalone exact checker passes 64 probability-triangle fixtures,
135 literal physical-overlap cases and 620 affine-kernel identity samples.
The new row has zero scalar and mean-square penalties and is valid for
every admissible mean. Its type is dyadic-subadditive-functional-v1.

For the current numerical virtual profile, an exact rational integration
of the selected N=1023, j=3 row gives

    -15464123939429793921025121 / 878750308761600000000000000000 < 0.

Thus that profile violates a necessary overlap condition. It is not an
admissible upper witness, or an optimum certificate. Its sampled roots
and other approximate conditions are not assumed by this exact test.

Adding rho*K to the unchanged current kernel, holding every original
coefficient fixed, gives an outward positive-part denominator derivative
interval at mean zero of approximately

    [-0.0000711141558566135, -0.0000251987530463081].

Both endpoints are negative. The numerator remains unchanged, so some
sufficiently small positive coefficient improves the mean-zero return.
The executed enclosure uses 200-bit Arb and four exact kernel controls.
This is a local existence conclusion, not an explicit global peak bound.
The original check took 129.708 seconds; the full exact interval and all
source hashes are in runs/hybrid102-dyadic-direction-v1.json.
